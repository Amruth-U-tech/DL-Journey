# Multi-Layer Perceptron (MLP) 🧠🔥

This experiment extends the basic perceptron into a multi-layer neural network capable of solving non-linear problems.

---

## 📌 Objective

To understand how adding hidden layers enables neural networks to learn complex patterns.

---

## ⚙️ Concepts Covered

- Feedforward neural networks  
- Hidden layers  
- Activation functions (ReLU, Sigmoid)  
- Backpropagation  
- Loss functions  

---

## 🛠️ Implementation Details

- Implemented using Python / PyTorch  
- Multiple layers with non-linear activations  
- Trained on general datasets  

---

## 🔄 Workflow

1. Input layer receives data  
2. Forward propagation through hidden layers  
3. Compute loss  
4. Backpropagation to update weights  
5. Repeat training  

---

## 📊 Observations

- Can solve non-linear problems  
- Performance depends on architecture and hyperparameters  
- More powerful than single-layer perceptron  

---

## 🎯 Learning Outcome

- Understanding deep learning fundamentals  
- Role of hidden layers in learning representations  
- Introduction to backpropagation
