# Recurrent Neural Network (RNN) – California Housing 🧠📈

This experiment explores the use of Recurrent Neural Networks (RNNs) on the California Housing dataset.

---

## 📌 Objective

To understand how RNNs can be applied to sequential or structured data and evaluate their performance on regression tasks.

---

## ⚙️ Concepts Covered

- Recurrent Neural Networks  
- Sequential data processing  
- Hidden states  
- Vanishing gradient problem  
- Regression using neural networks  

---

## 🛠️ Implementation Details

- Implemented using PyTorch  
- Applied RNN architecture to housing dataset  
- Focus on learning temporal/sequential patterns  

---

## 📂 Dataset

- California Housing dataset  
- Features include income, population, location, etc.  

---

## 🔄 Workflow

1. Load and preprocess dataset  
2. Structure input for sequential processing  
3. Build RNN model  
4. Train model using regression loss  
5. Evaluate performance  

---

## 📊 Observations

- RNNs can model dependencies in sequential data  
- Performance may be limited due to vanishing gradients  
- Not always optimal for static tabular datasets  

---

## 🎯 Learning Outcome

- Understanding how RNNs process sequences  
- Limitations of vanilla RNNs  
- Motivation for advanced models like LSTM  

---

## 🚀 Next Step

Explore LSTM to overcome RNN limitations
