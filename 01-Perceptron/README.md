# Perceptron Model 🧠

This experiment focuses on understanding the Perceptron, one of the most fundamental building blocks of neural networks.

---

## 📌 Objective

To implement and understand a simple linear classifier using the Perceptron algorithm.

---

## ⚙️ Concepts Covered

- Linear classification
- Activation functions
- Decision boundary
- Binary classification

---

## 🛠️ Implementation Details

- Implemented using Python
- Focus on understanding the math behind weight updates
- Training using simple datasets

---

## 🔄 Workflow

1. Initialize weights and bias  
2. Compute weighted sum  
3. Apply activation function  
4. Update weights using error  
5. Repeat for multiple epochs  

---

## 📊 Observations

- Works well for linearly separable data  
- Fails on non-linear problems  
- Helps build intuition for neural networks  

---

## 🎯 Learning Outcome

- Understanding how a basic neuron works  
- Foundation for more complex models like MLP and CNN  

---

## 🚀 Next Step

Move from single-layer perceptron to multi-layer networks (MLP)
