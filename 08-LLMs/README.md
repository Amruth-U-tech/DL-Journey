# Large Language Models (LLMs) – Transformers 🤖🧠

This section explores the use of pre-trained Large Language Models (LLMs) using the Hugging Face Transformers library.

---

## 📌 Objective

To understand how modern language models work and evaluate their ability to answer questions using pre-trained transformer architectures.

---

## 🧠 Concepts Covered

- Transformers architecture  
- Tokenization  
- Pre-trained language models  
- Text generation  
- Model evaluation  

---

## 🛠️ Implementation Details

- Built using Hugging Face Transformers  
- Used `AutoTokenizer` and `AutoModelForCausalLM`  
- Loaded pre-trained models for text generation and question answering  

---

## 📂 Contents

- `llm_experiment_1.ipynb` → Initial experiment with pre-trained LLM  

---

## 🔄 Workflow

1. Load pre-trained model and tokenizer  
2. Convert input text into tokens  
3. Generate responses using the model  
4. Evaluate responses based on correctness
